Checker admission, seven original fixture files, prelaunch plan, generated sources, goldens, reports, journals, console outputs and full 203-file source snapshot are included. Binary artifacts/, xsim.dir/ and .Xil/ trees are excluded. Nested original manifests describe their original runtime trees; the outer archive-manifest.json defines the preserved file set.
