# AutoRTL v4

An agentic system that writes and optimises Verilog for Xilinx FPGAs through
Vivado — designed so the harness, not the model, carries the intelligence.

## Quick start
```
pip install -r requirements.txt
python -m pytest tests/ -q                      # 84 harness tests

# optimise an existing design
python run.py optimize --design counter.v --tb counter_tb.v --top counter \
    --objective minimize_luts --vivado C:/AMDDesignTools/2025.2/Vivado/bin/vivado.bat \
    --xvlog .../xvlog.bat --xelab .../xelab.bat --xsim .../xsim.bat

# build from intent
python run.py build --spec curriculum/tier1/debouncer_build/spec.md

# resume a crashed run          # run the test curriculum
python run.py resume --run logs/run_v4_.../     python run.py bench --tier 0
```

## What's inside
- Verification ladder: static → xvlog → sim → synthesis, cheapest first
- Contract linter + stub elaboration before any code is generated
- Python golden models, autogenerated self-checking testbenches, and
  testbench qualification by bug injection
- Best-of-4 generation with architectural mutation prompts
- Vivado message-ID error taxonomy with severity promotion
- Timing Doctor: tool knobs → RTL surgery → replan
- Resumable FSM with budgets, caches, watchdog
- Skills (.claude/skills) as the knowledge system; routing.yaml as the
  model policy (Claude Code primary, NVIDIA NIM + OpenRouter fallbacks)

Read `docs/DESIGN.md` for the full architecture and `CLAUDE.md` for the
working protocol.
